# Приложение "Планировщик задач"

                                                                               Для чего создано приложение?



В современном мире у каждого человека ежедневно большое количество задач - нужно не забыть передать показания счетчиков, отправить проект на работе к указанному дедлайну, купить продуктов к праздничному столу. 
Из-за обилия задач легко что-то забыть или не успеть в срок - с решением этой проблемы и поможет планировщик задач.
В нем можно устанавливать как разовые задачи на определенную дату, так и повторяющиеся задачи с установленными пользователем правилами.



                                                                          Инструкция по запуску проекта локально.



1. Перейдите в корневую директорию проекта
2. Выполните команду: - go run main.go 

или с переменными окружения:

TODO_PASSWORD="ваш_пароль" \
TODO_PORT="ваш_порт" \
TODO_DBFILE="путь_к_бд" \
go run main.go

3. Доступ к приложению по умолчанию: http://localhost:7540
4. Доступ к приложению при указании порта: http://localhost:указанный_порт/login.html



                                                                         Инструкция по запуску тестов.



1. В файле settings.go установите для FullNextDate и Search значение tru
2. Так как реализованы все дополнительные задание, то тесты можно запускайте командой -

TODO_PASSWORD="Установленный пароль(при запуске программы с паролем)" \
TEST_TOKEN="Токен, который можно получить через инструменты разработчика в браузере" \
go test ./tests

Примечание: Токен можно получить через инструменты разработчика в браузере. Переменная TEST_TOKEN используется для предотвращения перезаписи токена при перезапуске.



                                                                        Инструкция по сборке проекта



1. В корне проекта запустите команду для сборки образа:

docker build -t todo-scheduler .

2. Далее можем запустить контейнер двумя способами.

Например, с установленными значениями порта, базы данных и пароля:

docker run -d -p 8080:8080 -v todo-data:/data -e TODO_PORT=8080 -e TODO_DBFILE="/data/scheduler.db" -e TODO_PASSWORD="123" --name todo-app1 todo-scheduler

Примечание: При изменении порта не забудьте обновить его значение после флага -p.

3. Можно запустить контейнер с дефолтными значениями, заложенными в приложении 

docker run -d -p 7540:7540 -v todo-data:/data --name todo-app todo-scheduler

4. Далее проверить работу приложения можно точно также, как при запуске локально
